== Zweck
Dieses Dokument beschreibt wesentliche Entwurfsentscheidungen auf Ebene der Komponenten und Module. Diese dienen als Vorgabe für die Implementierung und erleichtern das Systemverständnis. Es werden die Systemarchitektur, Klassenstrukturen, Sequenzabläufe und Schnittstellen dokumentiert.

== Systemübersicht

Die Spendex Finance Tracker Anwendung ist eine mobile React Native-App zur Verwaltung persönlicher Finanzen. Sie ermöglicht das Erfassen von Transaktionen, Kategorisierung von Ausgaben, Budget-Tracking und die Analyse von Ausgabenmustern. Ein besonderes Feature ist die KI-gestützte automatische Kategorisierung von Belegen via Kamera-Scan.

=== Technologie-Stack
* **Frontend Framework:** React Native mit Expo 
* **Programmiersprache:** TypeScript 
* **Styling:** NativeWind (TailwindCSS für React Native)
* **Navigation:** Expo Router
* **Datenbank:** SQLite (expo-sqlite) mit Drizzle ORM
* **State Management:** React Hooks
* **Internationalisierung:** i18next
* **Testing:** Jest mit React Native Testing Library
* **KI-Integration:** Google Gemini API 2.5-flash

=== Google Gemini API
Die Anwendung nutzt die Google Gemini API (Modell: gemini-2.5-flash) zur KI-gestützten Kategorisierung von Belegen. Über die Kamerafunktion erfasste Bilder werden an die Gemini API gesendet, welche die Transaktionen automatisch extrahiert und kategorisiert.

**Implementierung:** `src/utils/ai.ts`

**API-Endpunkt:** `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent`

**Funktionsweise:**

* Das aufgenommene Bild wird als Base64-kodierte Daten übertragen
* Ein strukturierter Prompt beschreibt die gewünschte Extraktion von Einzelposten (Name, Betrag, Kategorie)
* Die API liefert strukturierte JSON-Daten mit den erkannten Transaktionen zurück
* Die Kategorisierung erfolgt auf Basis der in der App definierten Kategorienhierarchie
* Mehrsprachige Unterstützung (DE/EN) wird über den Prompt gesteuert
