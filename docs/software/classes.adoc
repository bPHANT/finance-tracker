== Übersicht

Dieses Dokument beschreibt alle Klassen, Module und Funktionen des Finance Tracker Projekts.
Das Projekt ist eine React Native Applikation zur Verwaltung persönlicher Finanzen mit TypeScript, SQLite-Datenbank und Expo.

*Beschreibung:* Datenbankschema für Benutzerkonten.

*Felder:*

[cols="1,2,2"]
|===
|Feld |Typ |Beschreibung

|id
|integer (PK, autoincrement)
|Eindeutige ID

|createdAt
|timestamp
|Erstellungszeitpunkt

|updatedAt
|timestamp
|Aktualisierungszeitpunkt

|name
|text
|Name des Kontos

|balance
|real
|Kontostand (Default: 0)

|color
|text (enum)

== Utility-Module

=== AI-Modul (utils/ai.ts)

*Beschreibung:* Integration mit Google Gemini API für KI-gestützte Belegkategorisierung.

==== useAi Hook

===== categorizePicture()
[source,typescript]
----
async function categorizePicture(
  photo: CameraCapturedPicture,
  categories: any
): Promise<void>
----

*Parameter:*

* `photo: CameraCapturedPicture` - Foto vom Beleg
* `categories: any` - Verfügbare Kategorien

*Beschreibung:* Sendet ein Belegfoto an die Gemini API und extrahiert Transaktionsinformationen. Das Ergebnis wird im AsyncStorage gespeichert.

*Rückgabeformat:* Array von Objekten mit:

* `specific: string` - Originalbeschreibung
* `term: string` - Generalisierte Bezeichnung
* `amount: number` - Betrag (negativ = Ausgabe, positiv = Einnahme)
* `categoryId: number` - Zugeordnete Kategorie-ID

===== getPrompt()
[source,typescript]
----
async function getPrompt(categories: any): Promise<string>
----

*Parameter:*

* `categories: any` - Kategoriestruktur

*Rückgabe:* `Promise<string>` - Formatierter Prompt für die AI

*Beschreibung:* Generiert einen detaillierten Prompt für die Gemini API basierend auf der aktuellen Sprache und Kategoriestruktur.

== Seed-Daten

=== seedCategories (db/seed/categories.ts)

*Funktion:*
[source,typescript]
----
async function seedCategories(
  db: ExpoSQLiteDatabase<any>
): Promise<boolean>
----

*Parameter:*

* `db: ExpoSQLiteDatabase<any>` - Datenbank-Instanz

*Rückgabe:* `Promise<boolean>` - true wenn Seed durchgeführt, false wenn bereits vorhanden

*Beschreibung:* Fügt vordefinierte Kategorien in die Datenbank ein:

* Einnahmen (Werkstudentenjob, Stipendium, etc.)
* Essen & Trinken (Restaurant, Supermarkt, etc.)
* Freizeit (Sport, Konzerte, etc.)
* Wohnen (Miete, Nebenkosten, etc.)
* Reisen (Flüge, Hotels, etc.)
* Abos & Mitgliedschaften
* Versicherungen
* Universität (Semesterbeitrag, Bücher, etc.)
* Geschenke & Spenden
* Kleidung & Accessoires
* Technik & Elektronik
* Drogerie & Gesundheit

=== Verwendete Technologien

* **Framework:** React Native mit Expo
* **Programmiersprache:** TypeScript
* **Datenbank:** SQLite mit Drizzle ORM
* **State Management:** React Hooks

* **Styling:** NativeWind (Tailwind CSS für React Native)
